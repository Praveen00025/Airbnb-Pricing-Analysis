# 🏠 Airbnb Pricing Analysis

An exploratory data analysis project focused on understanding Airbnb listing prices, room types, neighbourhood trends, reviews, availability, and host performance using Python.

## 📌 Project Overview

This project analyzes Airbnb listing data to identify the major factors and patterns associated with listing prices.

The analysis includes data cleaning, exploratory data analysis (EDA), statistical summaries, correlation analysis, neighbourhood analysis, room-type comparison, host performance analysis, and review-based insights.

## 🎯 Objectives

- Analyze the distribution of Airbnb listing prices
- Compare prices across different room types
- Identify expensive neighbourhoods
- Analyze listing concentration across neighbourhoods
- Study the relationship between price, reviews, and availability
- Analyze host performance
- Identify potential best-value neighbourhoods
- Generate useful business insights from Airbnb listing data

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- Git & GitHub
